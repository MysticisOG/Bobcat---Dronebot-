As a young kid, I was invested in drones, RC aircraft and fighter jets.
But those are things for future me; current me is proud to say
that I developed a chatbot that assists you in your next
personal hobby drone build and also lets you set up alerts to
your favourite YouTubers and inspiration.
So please have fun with BOBCAT.

Features
- YouTube alerts
- drone builds for different goals
- real-time status
- socket mode integration

Commands
- /bobcat-summon - Check connection status
- /bobcat-drone fpv - Get FPV build specs
- /bobcat-drone budget - Get budget build specs
- /bobcat-drone cinematic - Get cinematic build specs
- /bobcat-yt - sets up YouTube channel alerts
